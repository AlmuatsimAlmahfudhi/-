# ألسُن — مغامرة تعلّم اللغات

منصة ويب لتعلم **الإنجليزية والفرنسية والإسبانية والصينية** من الصفر، بواجهة عربية كاملة، تعمل محلياً على جهازك، وتُفتح من الهاتف والآيباد كتطبيق.

- **المنهج:** الإطار الأوروبي (CEFR) من A1 إلى C2 للغات الأوروبية، ومعيار HSK 3.0 بمستوياته التسعة للصينية، ويسبقهما في كل لغة تأسيس في الحروف والأصوات (والبينيين والنغمات في الصينية).
- **محرك الحفظ:** تكرار متباعد بخوارزمية FSRS، مع بناء جمل ديناميكي من مفرداتك.
- **نظام لعب:** خبرة ومستويات وألقاب، وسلسلة يومية بدروع حماية، وإنجازات، ومهام يومية، ومتجر، وفئات أبطال بمزايا، وسمات تنمو، ومعارك زعماء.
- **الصوت:** محادثة صوتية فورية مع شخصيات بالذكاء الاصطناعي، وتقييم نطق مفصّل لكل كلمة ونغمة، ورسم منحنى نغمتك الصينية مقابل المنحنى الصحيح.

## أسهل طريقة: نقرة مزدوجة

الموقع **محلي بالكامل**: يعمل على حاسوبك ويُفتح في المتصفح، ولا يحتاج تثبيت أي تطبيق ولا رفعه على الإنترنت.

1. ثبّت Node.js من https://nodejs.org (مرة واحدة).
2. انقر نقراً مزدوجاً على:
   - **ويندوز:** `تشغيل-ويندوز.bat`
   - **ماك:** `تشغيل-ماك.command` (أول مرة: زر الفأرة الأيمن ← فتح)
3. يفتح المتصفح تلقائياً على http://localhost:3000. أبقِ النافذة السوداء مفتوحة أثناء الاستعمال.
4. لتفعيل الذكاء الاصطناعي ضع مفتاحك في ملف `.env.local` الذي يُنشأ تلقائياً، ثم أغلق النافذة وأعد التشغيل.

## التشغيل اليدوي (مرة واحدة)

تحتاج **Node.js 20 أو أحدث**: https://nodejs.org

```bash
cd alsun
npm install
cp .env.example .env.local
```

افتح `.env.local` وضع مفتاح Gemini:

```
GEMINI_API_KEY=المفتاح_هنا
```

> **عن مفتاح Gemini:** اشتراك «Google AI Pro» في تطبيق Gemini **منفصل** عن مفتاح المطورين (API). المفتاح يُنشأ مجاناً من https://aistudio.google.com/apikey وله حصة مجانية يومية تكفي الاستعمال الشخصي غالباً. الموقع يعمل بلا مفتاح أيضاً، لكن تتعطل المحادثة الصوتية وتقييم النطق المتقدم ودروس المستويات من A2 وHSK2 فما فوق.

## التشغيل اليومي

```bash
npm run build
npm run start
```

ثم افتح http://localhost:3000

للتطوير مع إعادة التحميل التلقائي: `npm run dev`.

### الفتح من الهاتف أو الآيباد

يشترط المتصفح اتصالاً آمناً (HTTPS) لاستعمال الميكروفون من جهاز آخر. لذلك:

```bash
npm run dev:lan
```

1. اعرف عنوان حاسوبك في الشبكة (مثلاً `192.168.1.20`).
2. افتح من الهاتف `https://192.168.1.20:3000` واقبل تحذير الشهادة.
3. من قائمة المشاركة اختر «إضافة إلى الشاشة الرئيسية» ليعمل كتطبيق.

يجب أن يكون الهاتف والحاسوب على شبكة الواي فاي نفسها، وأن يبقى الحاسوب مفتوحاً.

### لماذا هذه التقنيات؟

| الطبقة | الاختيار | السبب |
|---|---|---|
| الإطار | Next.js 16 (App Router) | واجهة وخادم في مشروع واحد، ومسارات API تحمي مفتاح Gemini، وتصدير PWA |
| الواجهة | Tailwind CSS 4 + Motion | تصميم للمس أولاً، ودعم RTL أصيل، وحركات لعب سلسة (سحب البطاقات، اهتزاز الزعيم) |
| قاعدة البيانات | SQLite عبر libsql + Drizzle | الموقع لمستخدم واحد ومحلي، فلا حاجة لـ Supabase وخوادمه. ملف واحد يُنسخ احتياطياً، والترحيلات تلقائية، والأنواع آمنة |
| التكرار المتباعد | ts-fsrs (FSRS) | أدق من SM-2 القديمة، وهي الخوارزمية الحديثة المعتمدة في Anki |
| الذكاء الاصطناعي | Gemini (‏@google/genai) | يوافق اشتراكك، ويجمع في مزوّد واحد: Live API للمحادثة الصوتية الأصلية، وفهم الصوت لتقييم النطق، وTTS، ومخرجات JSON مضبوطة بمخطط |
| الحروف الصينية | hanzi-writer | رسوم متحركة لترتيب الضربات |
| النطق المجاني | Web Speech API | يعمل بلا مفتاح كبديل للتعرف على الكلام والنطق |

### منهج «المزيج»

- **مكتوب مسبقاً** (في `src/content`): التأسيس الكامل لكل لغة، أي الحروف وأصواتها ونطقها التقريبي بالعربية، والنغمات الأربع وحروف البينيين وقواعد تغيّر النغمة وأول الحروف الصينية. ومعه ثماني وحدات كاملة للمستوى A1 وHSK1، فيها المفردات والجمل وشرح القواعد و«جسر من العربية» يقارن كل قاعدة بالعربية.
- **يولّده الذكاء الاصطناعي:** المستويات من A2 حتى C2 ومن HSK2 حتى HSK9 مبنية كخريطة مواضيع ونقاط نحوية محددة لكل مستوى. يُولَّد الدرس عند فتحه أول مرة بمراعاة الكلمات التي تعرفها، ثم يُحفظ. ويضيف الذكاء الاصطناعي أيضاً جملاً جديدة من مفرداتك في دروس الجمل ومعارك الزعماء.
- **مشترك بينهما:** محرك التمارين المحلي واحد للنوعين، فيحوّل أي عناصر إلى سبعة أنواع من التمارين: بطاقة تعريف، واختيار من متعدد بأربعة أنماط، وتوصيل، وبناء جملة، وكتابة، ونطق، وتمييز نغمات.

## مخطط قاعدة البيانات

المنهج بيانات ثابتة مُصنَّفة الأنواع في الكود، وترتيبه: `Course ← LevelDef (FOUNDATION, A1..C2 | HSK1..HSK9) ← Unit ← Lesson ← Item`. أما قاعدة البيانات فتحفظ حالة المتعلم فقط (`src/db/schema.ts`):

| الجدول | الغرض |
|---|---|
| `profile` | صف واحد: الاسم، فئة البطل، الخبرة، الأحجار، السلسلة، الهدف اليومي، مضاعف الخبرة، الإعدادات |
| `language_progress` | لكل لغة: الخبرة والمستوى الحالي في الإطار |
| `skill_stats` | سمات البطل لكل لغة: استماع، محادثة، نطق، قراءة، كتابة، مفردات، قواعد |
| `lesson_progress` | التيجان (0 إلى 3) وأفضل دقة وعدد مرات الإكمال لكل درس |
| `srs_cards` | بطاقات FSRS: الاستحقاق والثبات والصعوبة والحالة وعدد مرات النسيان |
| `review_logs` | سجل كل مراجعة لتحليل الأداء |
| `xp_events` | كل خبرة مكتسبة مع يومها ومصدرها، ومنها يُحسب الهدف اليومي والرسم الأسبوعي |
| `achievements` | الإنجازات المفتوحة |
| `daily_quests` | تقدم المهام اليومية |
| `inventory` | أدوات المتجر: درع السلسلة، جرعة الحياة |
| `counters` | عدادات الإنجازات |
| `ai_cache` | الدروس المولَّدة محفوظة |
| `conversations` | نصوص المحادثات الصوتية وتقييمها |
| `pronunciation_attempts` | محاولات النطق ودرجاتها |

النسخ الاحتياطي: صفحة البطل ثم «تصدير» أو «استيراد».

## قواعد اللعب (`src/lib/game-rules.ts`)

- **الخبرة:** 10 لكل إجابة صحيحة، وتزيد 10% مع كل إجابة صحيحة متتالية حتى تتضاعف. يُضاف 15 لإكمال الدرس و25 للدرس الخالي من الأخطاء، وتتضاعف الخبرة كلها عند هزيمة الزعيم.
- **التيجان:** تاج واحد عند إكمال الدرس، وتاجان بدقة 80% أو أكثر، وثلاثة بدقة 95% أو أكثر.
- **معركة الزعيم:** ثلاثة دروع، وكل خطأ يكسر درعاً. فئة المحارب قد تضرب ضربة مزدوجة، وجرعة الحياة تعيد درعاً.
- **التعلم بالإتقان:** السؤال الذي تخطئ فيه يعود مرة أخرى في آخر الدرس.
- **السلسلة:** تُحسب عند بلوغ هدفك اليومي. يُستهلك درع السلسلة تلقائياً إن غبت يوماً، وفئة الرحّالة تكسب درعاً مجانياً كل سبعة أيام متتالية.
- **الفئات:** الحكيم (+20% خبرة من المراجعة)، والمحارب، والخطيب (+30% خبرة من النطق والمحادثة)، والرحّالة.

## هيكل الملفات

```
src/
  content/        المنهج: en/fr/es/zh، أطر CEFR وHSK، سيناريوهات المحادثة
  db/             مخطط Drizzle والاتصال بالترحيل التلقائي
  server/         منطق اللعب، FSRS، تكامل Gemini
  lib/            محرك التمارين، الصوت، البينيين، قواعد اللعب
  hooks/          التسجيل، التعرف على الكلام، المحادثة الحية
  components/     الواجهة ومكوّنات التمارين
  app/            الصفحات: الرئيسية، المغامرة، الدرس، المراجعة، المحادثة، البطل + مسارات API
drizzle/          ترحيلات SQL
data/             قاعدة بياناتك وملفات النطق المخزنة (غير مرفوعة إلى Git)
```
